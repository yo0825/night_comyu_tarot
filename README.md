# 星の余韻

ZIPを展開して index.html を開くと使えます。

## 使い方

1. ワークシートの「つながり」「喜び」「挑戦」「成長」を貼り付けます。1項目以上あれば進めます。
2. プロンプトを作成し、「ChatGPTを開く」を押します。URLの q パラメータにプロンプト全文を入れて別タブへ渡します。
3. 完成画像を保存し、ワークシートに貼り付けます。

入力欄は毎回空欄から始まり、例文はプレースホルダーとしてのみ表示します。入力内容の自動保存・復元は行いません。「入力をクリア」では、現在の入力と、このブラウザに以前保存された下書きを消去できます。
自動コピーできない環境では文章が選択表示されるので、長押し、または Ctrl+C / ⌘C でコピーしてください。「プロンプトを確認」内の「文章をコピー」も使えます。
ChatGPTへうまく渡らないときは「プロンプトを確認」を開き、「全文を選択」から手動でコピーしてください。「テキストを保存」からプロンプトを保存することもできます。
ChatGPT側でログインが必要な場合があります。URLでの受け渡しはChatGPT側の動作に依存するため、すべてのブラウザやアプリでの自動送信を保証するものではありません。プロンプトを含むURLがブラウザの履歴に残る場合があります。

## 更新するファイル

index.html、app.js、styles.css をまとめて上書きしてください。
assets フォルダには次の4枚の見本と4つのアイコンを配置してください。以前の見本画像と layout_reference.png は使いません。

- sample-canele.webp
- sample-tart.webp
- sample-macaron.webp
- sample-montblanc.webp
- favicon.svg
- favicon.ico
- apple-touch-icon.png
- web-icon.png

直前の版からは index.html、app.js、styles.css を上書きしてください。アイコンと見本画像の変更はありません。

GitHub Pagesでは .nojekyll も公開元フォルダに配置します。

入力欄と生成プロンプト内の順番は「つながり → 喜び → 挑戦 → 成長」です。見出しはワークシートに合わせています。薄い例文は入力内容としては扱いません。プライバシー・プロンプト・クリア確認は、右上の × または Esc キーで閉じられます。
