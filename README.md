# 星の余韻 2026｜最終版

## 使い方

### かんたん公開（推奨）
1. 「1ファイル版」の ZIP を展開する
2. 中の `index.html` を GitHub のリポジトリ直下に置き、既存の `index.html` と置き換える
3. GitHub Pages のデプロイ完了後にサイトを再読み込みする

### ファイル分割版
`index.html`、`styles.css`、`app.js`、`assets/` フォルダをそのままリポジトリ直下に配置します。

## 機能
- 4種のカード見本が自動で切り替わるトップ画面
- 2項目だけの振り返り入力と保存
- ChatGPT Webへの画像生成プロンプト受け渡し
- 画像内の固定見出し「あなたのタイプ」「今年頑張ったこと」「来年のアクション」
- 画像は縦長2:3・1人1枚・日本語句読点なしを指定
- 生成後の画像読み込み、X投稿文編集・コピー・Xの投稿画面を開く機能
- 対応端末では画像と文章のネイティブ共有

## 注意点
- `https://chatgpt.com/?q=...` によるURL経由の連携は公式に保証されたAPIではありません。自動送信される場合もあるため、公開後の動作確認をしてください。
- GitHub Pages（静的サイト）からXへ画像を完全自動添付することはできません。対応端末ではOSの共有機能を利用できます。その他の環境はX上で手動添付してください。
- 入力文章はブラウザのlocalStorageに保存され、ChatGPT遷移時はURLに含まれます。個人情報や機密情報を入力しないでください。
- 画像生成結果の文字・構図は保証できません。見本は静的カードとして正確な文字で組版してあります。
