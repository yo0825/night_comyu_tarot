# 星の余韻

ZIPを展開して index.html を開くと使えます。

## 使い方

1. ワークシートの「つながり」「喜び」「挑戦」「成長」を貼り付けます。1項目以上あれば進めます。
2. プロンプトを作成し、「ChatGPTを開く」を押します。別タブへ文章を渡し、クリップボードにもコピーします。
3. 文章が渡らない場合は「プロンプトをコピー」でコピーし、ChatGPTに貼り付けて送信します。
4. 完成画像を保存し、ワークシートに貼り付けます。

入力はこのブラウザに保存され、「入力をクリア」で消去できます。
ChatGPTへのリンクはプロンプトをURLに含みます。長文ではトップページを開くため、コピーした文章を貼り付けてください。
ChatGPT側でログインが必要な場合があります。
