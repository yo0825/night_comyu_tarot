# 星のふりかえりカード v10

## できること
- 今年頑張ったこと と 楽しかったこと の2項目だけ入力
- ChatGPT Web を開き タロットカード画像を1枚生成
- 固定見出しは次の3つ
  - あなたのタイプ
  - 今年頑張ったこと
  - 来年のアクション
- 投稿文を自動生成し Xへ渡す
- 完成画像をアップロードするとプレビュー表示し 一部端末では画像つき共有可能

## ファイル構成
- index.html
- styles.css
- app.js
- assets/*.webp

## GitHub Pages 反映
1. 既存のリポジトリにこの一式をアップロード
2. `main` ブランチの `/ (root)` を Pages 公開対象にする
3. 反映後にブラウザを再読み込みする
