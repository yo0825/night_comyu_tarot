# 星の余韻 — カード見本4枚が必ず見える版

公開用ファイルは index.html / styles.css / app.js / assets/card_*.webp です。

## おすすめの公開方法

「1ファイル版」に含まれる index.html だけを GitHub のリポジトリ直下の index.html と置き換えてください。画像はファイル内に埋め込まれています。`assets` フォルダをアップロードする必要はありません。

## 表示されるもの
- トップ画面に4種類のカード見本サムネイル
- 右側に大きな完成見本。サムネイルをクリックして切り替え可能
- カードは約5.9秒ごとにゆっくり切り替わる
- 2項目のふりかえり、ChatGPTへの生成依頼、X用投稿文作成は従来通り

## 注意
- Xへの画像の完全自動添付はWebサイトの機能だけでは保証できません。対応端末ではOSの共有が使えます。
- ChatGPT WebへのURL連携は公式の安定した連携APIではありません。場合によってはコピーして貼り付けてください。
