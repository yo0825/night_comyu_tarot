# 星の余韻 v12 - 入力クリア・構図調整版

- 先ほどまでの大人っぽい星空・スイーツ水彩デザインは維持
- 画像生成プロンプトで **上部8%タイトル + 32%水彩画 / 下部57%の三段文章 + 最下部3%飾り** を指定
- 文章欄は3段とも「左に見出し／右に本文」形式
- 入力画面に「入力をクリア」を追加（確認付き）
- 入力を消した際は古いプロンプト・投稿文案も消去
- トップの流れ星、入力の星のきらめき、プロンプト前の光の演出を維持

## GitHub Pages
初心者向け：1ファイル版ZIPを解凍し、その`index.html`で既存ファイルを置き換えてください。
完全版：index.html, app.js, styles.css, assets/ の全ファイルを公開先のリポジトリ直下へ配置してください。

## 制限
ChatGPTへの `?q=` による受け渡しは環境によって動作が異なります。長文ならプロンプトをコピーして貼り付けてください。カード画像の完全な構図と日本語表記は画像モデルにより揺らぐため、厳密な保証はできません。
