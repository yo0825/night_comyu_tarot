# 星の余韻

ZIPを展開して index.html を開くと使えます。

## 使い方

1. ワークシートの「つながり」「喜び」「挑戦」「成長」を貼り付けます。1項目以上あれば進めます。
2. プロンプトを作成し、「ChatGPTを開く」を押します。コピーが完了してから別タブでChatGPTを開きます。
3. ChatGPTに貼り付けて送信します。別タブが開かない場合は、画面の案内に従ってもう一度「ChatGPTを開く」を押してください。
4. 完成画像を保存し、ワークシートに貼り付けます。

入力はこのブラウザに保存され、「入力をクリア」で消去できます。
自動コピーできない環境では文章が選択表示されるので、長押し、または Ctrl+C / ⌘C でコピーしてください。「プロンプトをコピー」だけを使うこともできます。
ChatGPT側でログインが必要な場合があります。
