# 星のふりかえり手帖｜Webアプリ全面改修版 v4

11月の夜活イベント「今年の自分におつかれさまを。来年への一歩を見つける夜」向けの、GitHub Pagesで公開できる静的Webアプリです。

## できること

- **最初の画面**：完成カードの画像が約4.8秒ごとに自動で切り替わります。星空からカードが降りて手元に届くアニメーションつき。左右の矢印とドットでも手動切り替えできます。
- **01 ふりかえり**：学び、つながり、楽しかったこと、今年の頑張りを記入。ヒントの言葉も使えます。
- **02 未来の一歩**：来年大切にしたいことと、12月に始める小さな行動を記入。
- **03 カードを選ぶ**：4つの色、12星座＋おまかせ、7つのスイーツ、主星3/5/7/9＋おまかせを選び、ChatGPTに画像生成を依頼します。
- **04 投稿文を書く**：Xに投稿する文章を自由に編集、コピー、Xの投稿画面へ移動。ChatGPTで保存した完成画像を、この画面にローカルで表示することもできます。
- 端末内の入力保存（localStorage）、入力の消去、振り返りのテキスト保存、モバイル画面対応。

## GitHub Pagesで公開する

1. ZIPを展開します。
2. `index.html`、`styles.css`、`app.js`、`assets/`フォルダーをまとめてリポジトリの公開用ディレクトリに配置します。
3. GitHubへコミットします。
4. GitHubの `Settings` → `Pages` からブランチ・公開フォルダを設定します（すでに公開済みなら通常は不要）。

サーバー・ビルド処理・APIキーは不要です。

## 利用時の注意

- 見本画像はユーザーからいただいた4種類のカードを使っています。元の見本は縦細ですが、**新しく生成する画像は縦横比2:3**を指定します。画像生成の性質上、寸法や文字の完全一致は保証されません。
- ChatGPTへの受け渡しには非公式な `https://chatgpt.com/?q=...` のURL方式を使います。動作変更、URL長、ブラウザのポップアップ制限等で自動入力されない場合があります。生成プロンプトのコピーボタンを代替手段として用意しています。
- フォームの入力内容はURLに含まれ得ます。**氏名・住所・機密情報を入力しない**でください。
- アプリはXへ画像を自動添付できません。画像はChatGPTから保存し、Xの投稿画面で添付してください。アプリ内の画像アップロードは端末上のプレビューのみで、サーバー送信しません。
- アニメーションはユーザーの `prefers-reduced-motion` 設定に配慮して停止します。

## 手元で確認するには

ZIPを展開後、`index.html` をブラウザで開いてください。GitHub Pagesに公開した場合は、公開URLから動作確認できます。
