# 星の余韻 — 完全版 v8

2026年11月の夜活イベント向け、「一年の振り返り × 星座 × スイーツ × タロット」の静的Webアプリです。GitHub Pagesで公開できます。

## 画面の流れ

1. 星のタロット見本が切り替わるトップ画面
2. 今年の頑張り（必須）・楽しかったことやつながり（任意）の2項目を入力
3. ChatGPT Webに遷移して、本人の言葉からカード画像を1枚生成
4. X投稿文を編集・コピーし、生成したカード画像を選んでプレビュー

カードのデザイン・星座・スイーツ・2027年の新しい挑戦はユーザーに選ばせず、画像生成用プロンプトでChatGPTに提案させます。

## GitHub Pagesにアップロード

1. ZIPを解凍します。
2. `https://github.com/yo0825/night_comyu_tarot` を開き、リポジトリ直下（`main`ブランチ）に `index.html`、`styles.css`、`app.js`、`assets`フォルダをアップロード・上書きします。
3. `assets` の画像が `assets/sample_1.webp` などのパスになるようにしてください。
4. `Commit changes` を押すと、設定済みのGitHub Pagesが更新されます。表示されないときは GitHubの `Actions` のデプロイ結果を確認してください。
5. ブラウザのキャッシュが古い場合は `Ctrl+Shift+R` で再読み込みします。

**より簡単な方法:** 別添の「1ファイル公開版」の `index.html` だけをリポジトリ直下に上書きしてください。画像・CSS・JavaScriptがすべてHTML内にあるため、`assets`フォルダのアップロードは不要です。

## 動作上の留意点

- 利用者の入力内容はブラウザ内の `localStorage` に自動保存されます。サーバーへの保存機能はありません。
- ChatGPTは `https://chatgpt.com/?q=...` を使って別タブで開きます。この方式は公式に保証された連携APIではありません。環境によっては入力が引き継がれなかったり、送信の挙動が異なったりする場合があります。
- プロンプトが長すぎる場合やタブが開けなかった場合は「生成用の文章を確認・コピーする」から文章をコピーし、ChatGPTに貼り付けられます。
- URLに振り返り本文が含まれるため、氏名や社内の機密事項などは入力しないでください。
- ChatGPTで作成した画像が自動でWebアプリに戻るわけではありません。ChatGPTで画像を保存し、Webアプリの最終画面で必要に応じて画像を選択してください。
- Xの投稿画面にはテキストのみが渡されます。画像はX側で手動添付してください。
